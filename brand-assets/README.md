# brand-assets

Single source of truth for the 100 Plus Academy brand (logos, colors, fonts,
contact details, tone). **Always follow it for every image and post.**

- `BRAND_GUIDELINES.md` - human-readable rules
- `brand.json` - same data, machine-readable
- `logos/` - official logo files (composite these; never AI-draw the logo)

Add new official assets (hi-res logo, photos, templates) here and update the
guidelines. Do not add real student/teacher photos without consent.
